# Hydrovel

O Hydrovel é um projeto de conclusão de curso voltado ao desenvolvimento de um sistema de Internet das Coisas (IoT) para monitoramento residencial do consumo e das condições da água. O projeto tem como finalidade auxiliar na identificação de vazamentos, alterações no fluxo hidráulico e possíveis alterações na qualidade da água, disponibilizando os dados coletados de forma remota por meio de uma interface digital.

## Problema

Vazamentos residenciais não identificados podem provocar desperdício significativo de água, aumento nas despesas e danos à infraestrutura. Além disso, a qualidade da água armazenada em caixas d'água normalmente não é monitorada de forma contínua, dificultando a identificação de alterações que possam comprometer sua utilização. Outro problema é a ausência de acompanhamento remoto. Em sistemas convencionais, o morador geralmente depende de inspeções presenciais ou da percepção de sinais visíveis para identificar problemas hidráulicos ou alterações na água.

## Justificativa

O desenvolvimento do Hydrovel é motivado pela necessidade de tornar o monitoramento residencial da água mais acessível, contínuo e informativo. A utilização de sensores permite obter dados quantitativos sobre o sistema hidráulico e sobre características da água, enquanto a plataforma digital possibilita acompanhar essas informações remotamente. A proposta também busca contribuir para o consumo consciente de água, permitindo identificar comportamentos anormais e possíveis desperdícios antes que provoquem prejuízos maiores.

## Objetivo Geral

Desenvolver um sistema IoT capaz de monitorar o fluxo e parâmetros de qualidade da água em uma residência, identificar possíveis anormalidades, transmitir os dados para um servidor e disponibilizar as informações ao usuário por meio de uma interface digital. Monitorar a vazão e a pressão do sistema hidráulico. Identificar alterações anormais no comportamento do fluxo de água. Monitorar parâmetros relacionados à qualidade da água. Coletar dados utilizando sensores conectados a um ESP32. Transmitir os dados coletados para um servidor. Disponibilizar as informações em um dashboard ou aplicativo. Permitir acompanhamento remoto das medições. Gerar alertas em situações consideradas anormais. Utilizar análise de dados para auxiliar na identificação de possíveis vazamentos e irregularidades. Contribuir para a redução do desperdício de água e para o uso consciente do recurso.

## Escopo

O Hydrovel concentra-se no monitoramento residencial de sistemas hidráulicos. O protótipo será responsável pela coleta de dados físicos, processamento inicial das informações, transmissão dos dados e apresentação dos resultados ao usuário. O sistema será dividido em duas áreas principais: hardware e software. No hardware, sensores instalados no sistema hidráulico realizarão as medições de pressão, vazão e parâmetros relacionados à qualidade da água. Um ESP32 será utilizado como unidade de controle e comunicação. No software, os dados recebidos serão processados e disponibilizados ao usuário por meio de uma interface de monitoramento, permitindo visualizar medições, histórico, alterações e alertas. O projeto não tem como objetivo substituir análises laboratoriais ou profissionais especializados em tratamento de água. Seus resultados serão utilizados como indicadores para monitoramento e identificação de possíveis anormalidades. A arquitetura geral do Hydrovel é composta por quatro etapas de:
1. Sensores: realizam a coleta dos dados do sistema hidráulico e da água.
2. ESP32: recebe e processa inicialmente os dados dos sensores.
3. Servidor: recebe, armazena e processa as informações enviadas pelo dispositivo.
4. Dashboard ou aplicativo: apresenta os dados ao usuário e permite o acompanhamento remoto.
   
## Hardware

O principal controlador previsto para o protótipo é o ESP32, responsável pela integração dos sensores, processamento das leituras e comunicação com o sistema remoto. Os sensores apresentados na arquitetura do projeto são divididos em duas categorias. Sensor de pressão e de vazão. A análise conjunta desses dados permitirá identificar alterações no comportamento normal do sistema hidráulico e auxiliar na detecção de possíveis vazamentos ou fluxos irregulares. Os Sensores para monitoramento da qualidade são o de PH, de turbidez e de temperatura. Esses sensores fornecerão dados para acompanhamento das condições da água armazenada, permitindo identificar alterações nos parâmetros monitorados. Durante a fase inicial do projeto também foram considerados o sensor de fluxo YF-S201 para medição da passagem de água e o sensor de turbidez ST100. A definição final dos componentes poderá ser ajustada de acordo com os testes e a disponibilidade dos equipamentos.

## Software

A arquitetura de software prevista para o Hydrovel possui as seguintes funções: Firmware do ESP32 para leitura dos sensores, Comunicação entre o dispositivo e o servidor, API ou serviço responsável pelo recebimento dos dados, Banco de dados para armazenamento das medições, Processamento e análise dos dados, Dashboard ou aplicativo para visualização, Sistema de alertas para situações anormais. Como tecnologias de desenvolvimento, poderão ser utilizados C/C++ no firmware do ESP32, Python para processamento e análise dos dados, MQTT ou HTTP para comunicação, banco de dados para armazenamento das séries de medições e Flutter para desenvolvimento da interface multiplataforma. A definição definitiva da stack ocorrerá durante a implementação e os testes do protótipo.

## Análise Preditiva

Um dos diferenciais do Hydrovel é a utilização de análise de dados para identificar comportamentos anormais. O sistema poderá comparar as medições atuais com padrões históricos de consumo e funcionamento do sistema hidráulico. Alterações significativas no comportamento esperado poderão ser classificadas como possíveis anomalias. Entre os exemplos de análise estão: aumento inesperado da vazão; fluxo contínuo durante períodos de baixa utilização; alterações anormais de pressão; mudanças relevantes nos parâmetros monitorados da água; identificação de padrões que possam indicar vazamentos. A análise preditiva será desenvolvida progressivamente a partir dos dados coletados durante os testes do protótipo. O usuário poderá acompanhar as informações coletadas pelo sistema remotamente por meio da interface desenvolvida com informações previstas como consumo e fluxo de água; pressão do sistema; parâmetros de qualidade; histórico das medições; possíveis anomalias; alertas relacionados a comportamentos fora do padrão. Quando o sistema identificar uma situação considerada anormal, poderá emitir um alerta para informar o usuário e permitir uma verificação do sistema hidráulico.

## Metodologia

O projeto utiliza uma abordagem quantitativa, baseada na coleta e análise de dados provenientes dos sensores. A metodologia será desenvolvida em etapas de Pesquisa bibliográfica sobre IoT, sistemas hidráulicos, sensores, monitoramento da água, análise de dados e detecção de anomalias. Definição dos requisitos do sistema. Seleção dos componentes eletrônicos e tecnologias. Desenvolvimento do protótipo físico. Programação do ESP32. Integração dos sensores. Desenvolvimento do servidor e sistema de armazenamento. Desenvolvimento da interface de monitoramento. Realização de testes. Coleta de dados. Análise dos resultados. Ajustes e validação do protótipo. Documentação dos resultados e elaboração do TCC.

## Hipótese

A hipótese do projeto é que a ausência de um sistema acessível de monitoramento contínuo dificulta a identificação de desperdícios, vazamentos e alterações nas condições da água. A implementação de um sistema IoT de baixo custo e monitoramento remoto poderá fornecer informações que auxiliem os residentes a identificar anormalidades, utilizar a água de maneira mais consciente e realizar verificações preventivas no sistema hidráulico. Espera-se que o Hydrovel seja capaz de: realizar medições dos parâmetros definidos no protótipo; registrar os dados coletados; transmitir as informações ao servidor; apresentar os dados de maneira compreensível; identificar comportamentos anormais no fluxo de água; auxiliar na identificação de possíveis vazamentos; apresentar informações relacionadas à qualidade da água; emitir alertas para situações anormais; permitir acompanhamento remoto; contribuir para a redução do desperdício de água com os Componentes eletrônicos necessários para montagem do protótipo, C/C++ para programação do microcontrolador, Python para processamento e análise de dados, MQTT e/ou HTTP para comunicação, Banco de dados para armazenamento das medições, Flutter para aplicativo e interface multiplataforma, Dashboard para visualização dos dados com o funcionamento do Hydrovel pode ser representado pelo seguinte fluxo de Coleta dos dados → Processamento no ESP32 → Transmissão → Servidor → Armazenamento → Análise → Dashboard/Aplicativo → Alertas ao usuário. O desenvolvimento do projeto está organizado em etapas de planejamento, pesquisa, desenvolvimento do protótipo, integração dos sensores, desenvolvimento do software, coleta de dados, análise, testes, validação e documentação. O cronograma contempla inicialmente a elaboração e entrega do projeto, pesquisa bibliográfica, coleta de dados, desenvolvimento do sistema, apresentação e discussão dos resultados, elaboração da conclusão, entrega do TCC e defesa perante a banca.

## Limitações

O Hydrovel é um protótipo acadêmico e seus resultados dependem da precisão, calibração e condições de funcionamento dos sensores utilizados. As informações fornecidas pelo sistema possuem finalidade de monitoramento e identificação de possíveis anormalidades. A avaliação definitiva da potabilidade ou da segurança microbiológica da água exige métodos e análises apropriados realizados por profissionais ou laboratórios especializados. Busca demonstrar como tecnologias de IoT podem ser aplicadas ao monitoramento residencial de recursos hídricos. A integração entre sensores, microcontrolador, comunicação de dados, servidor, análise e interface de monitoramento possibilita transformar medições físicas em informações úteis para tomada de decisão. O projeto possui como principais contribuições a identificação preventiva de possíveis vazamentos, o acompanhamento de parâmetros da água, o monitoramento remoto e o incentivo ao uso consciente dos recursos hídricos.
